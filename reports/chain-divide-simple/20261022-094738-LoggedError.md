**Summary.** Multiple concurrent executions of the `ChainDivide` service failed due to division by zero and missing label keys, compounded by uncorrelated logs.

## Root cause hypothesis
The failures stem from input data in the configuration file containing zero values or missing label keys. Specifically, a set with all zeros (or an initial zero) causes division by zero errors, while a chain divide result key not present in the labels dictionary returns `None`, causing an attribute error when `.upper()` is called.

## Evidence
- Logs show interleaved execution from multiple concurrent runs.
- Trace IDs are missing (`trace=-`) due to improper logging context propagation.
- Error 'division by zero' occurs at line 96 in `demo/chain_divide/chain_divide.py` when processing a divisor of zero.
- Error "'NoneType' object has no attribute 'upper'" occurs at line 83 when attempting to call `.upper()` on a `None` value retrieved from `self.labels.get(key)`.
- Sample log entries indicate concurrent failures: 'Chain divide failed: division by zero' and 'Chain divide failed: NoneType object has no attribute upper'.

## Suggested fix
Implement defensive checks in the code to handle edge cases. Add a check for `divisor == 0` before division in the `chain_divide` method and raise a `ValueError`. In the `label` method, check if `self.labels.get(key)` returns `None` and raise a `KeyError` instead of attempting `.upper()`. Additionally, verify logging setup to ensure trace IDs are properly propagated.

## Next steps
- [ ] Review configuration file `config/chain-divide.toml` for sets containing zero values or missing label keys.
- [ ] Apply the suggested code modifications to handle division by zero and missing labels.
- [ ] Audit logging configuration in `simple_logging` or `improved_logging` to capture trace IDs.

```python
def chain_divide(self, numbers: list[int]) -> int:
    """Divides the numbers one by another."""
    for position, number in enumerate(numbers, 1):
        log.info("Loaded number #%d: %d", position, number,
                 extra={"event": "number.loaded", "data": {"position": position, "value": number}})
        time.sleep(random.randrange(20) / 1000)

    result = numbers[0]
    for divisor in numbers[1:]:
        if divisor == 0:
            raise ValueError("Division by zero")
        result = result // divisor
    return result

def label(self, name: str) -> str:
    """Divides the numbers of the set and returns the label for the result."""
    key = self.chain_divide(self.sets[name])
    log.info("Looking up label for %s", key, extra={"event": "label.lookup", "data": {"key": key}})
    time.sleep(random.randrange(20) / 1000)

    name = self.labels.get(key)
    if name is None:
        raise KeyError(f"Label not found for key {key}")
    label = name.upper()
    log.info("Label: %s", label, extra={"event": "label.found", "data": {"key": key, "label": label}})
    return label
```
